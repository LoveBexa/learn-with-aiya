# AIYA

AIYA is a hands-on workshop experience for non-technical people who want to build real things with AI.

This repository is a plain static website — no build step, no npm install required.

## What’s included

- A polished landing page for the AIYA experience
- Workshop highlights and classroom-focused content
- Theme toggle and animated visual styling

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/ in your browser.

## Files

```
index.html      — main page (also available as aiya.html)
css/styles.css  — all styles
js/main.js      — animations and interactions
images/         — put image assets here
```

## Deploy to Hostinger

Upload these files and folders directly into `public_html`:

- `index.html`
- `aiya.html`
- `css/` folder
- `js/` folder
- `images/` folder (when you have assets)

No build step needed — what you see locally is what goes live.

## Deployment

This site can be deployed as a static website on Hostinger, GitHub Pages, or any host that serves HTML files.
