Prompt to Vibecoding

You've prompted AI for words and images. Now build something that actually runs.

  • 01

    Go from prompting to building

    Take everything you already know about prompting and put it to work vibecoding a real piece of software alongside the instructor.

  • 02

    Learn the method

    Learn a simple, re-usable way to describe what you want and let AI write, run and fix the code — no syntax to memorise.

  • 03

    Take it further

    Leave with a working app and the confidence and skills to keep vibecoding your own ideas.

If you've used ChatGPT or Claude to write emails, brainstorm ideas or generate images, you've already been prompting AI. This workshop is about what happens when you point that same skill at building software instead.

This is a hands-on introduction to vibecoding — describing what you want in plain English and letting AI write, run and fix the code for you. We'll guide you through turning an idea into a working tool, step by step. You'll learn how to:

  • Describe an idea clearly enough for AI to build it
  • Prompt AI to write, run and preview real code
  • Work with AI to change, fix and improve what it builds
  • Spot and describe bugs without needing to read the code yourself
  • Take the same approach and apply it to your own ideas

The goal isn't to become a developer. It's to realise that vibecoding is just prompting, one level further — and that you can already do it.

What you'll actually make

A simple working web app, built entirely by prompting:

  1. Describe your idea

    Turn a rough idea into a clear brief AI can build from — no technical spec required.

  2. Vibecode it into shape

    Prompt AI to build, preview and adjust your app in real time until it looks and works the way you pictured it.

  3. Ship something real

    Turn your working app into something you can open in a browser and actually show people.

Who's it for?

  • You've only used AI for promptingYou use ChatGPT or Claude for emails, copy, research and images, but haven't tried using it to build anything you can actually run.
  • You're curious about vibecodingYou've heard the term, seen the demos, and want to know if it's really as accessible as people say — and try it for yourself.
  • You have an idea for an app or toolYou don't want to become a developer. You just want to know what's possible — and have a go at building it yourself.
